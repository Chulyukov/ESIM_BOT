# ESIM_BOT – Telegram-бот для продажи туристических eSIM

Данный проект представляет собой Telegram-бота на Python, предназначенного для автоматизации полного цикла продаж туристических eSIM. Бот предоставляет пользователям удобный интерфейс для покупки зарубежных пакетов интернета, расчетов стоимости и мгновенного получения QR-кодов профилей связи.

## 🚀 Основные возможности

* **Полный цикл покупки:** От приветствия (`c_start.py`) до выбора тарифа и оформления заказа (`c_buy_esim.py`) прямо в интерфейсе Telegram.
* **Интеграция с провайдером:** Прямое взаимодействие с API телеком-провайдера (Monty) для выпуска новых профилей связи (`monty_api.py`).
* **Мультивалютность и расчеты:** Встроенный модуль обработки курсов валют (`currency_rate.py`) для динамического расчета стоимости тарифов.
* **Управление профилями:** Возможность управления выпущенными eSIM, включая логику их удаления/деактивации (`delete_esim.py`).
* **База данных:** Структурированное хранение информации о пользователях, заказах и транзакциях (`db_queries.py`).

## 📁 Структура проекта

```
├── main.py                     # Главный файл, точка входа и запуск бота
├── requirements.txt            # Зависимости проекта (библиотеки Python)
├── monty_api.py                # Модуль интеграции с API Monty (запрос eSIM)
├── currency_rate.py            # Модуль для получения курсов валют и расчетов
│
├── core/                       # Основная бизнес-логика и обработчики (handlers)
│   ├── c_start.py              # Обработка команды /start и главного меню
│   ├── c_buy_esim.py           # Логика флоу покупки eSIM
│   ├── delete_esim.py          # Логика деактивации/удаления профилей
│   └── helpful_methods.py      # Вспомогательные функции и утилиты
│
└── db/                         # Работа с базой данных
    ├── db_connection.py        # Инициализация и настройка подключения к БД
    └── db_queries.py           # SQL-запросы для работы с данными бота
```

## 🛠 Установка и запуск

### 1. Клонирование репозитория

Скопируйте проект на свой локальный сервер:

```bash
git clone <URL_вашего_репозитория>
cd ESIM_BOT
```

### 2. Настройка виртуального окружения

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate  # Для Linux/MacOS
# или
venv\Scripts\activate     # Для Windows
```

### 3. Установка зависимостей

Установите все необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Вам потребуется создать файл `.env` (или настроить `config`, если он используется в проекте) и указать необходимые ключи доступа:
* Токен Telegram-бота (Bot API)
* Ключи доступа к Monty API
* Доступы к базе данных (например, PostgreSQL или SQLite)
* Токен платежной системы (при наличии)

### 5. Запуск приложения

Запустите бота через основной файл:

```bash
python main.py
```
*(Для работы в production-среде рекомендуется использовать systemd или Docker, а также настроить Webhooks вместо обычного Polling).*

## 💡 Архитектура
Проект разделен на логические слои: `core` отвечает за интерфейс и общение с пользователем в Telegram, `db` инкапсулирует логику работы с хранилищем, а модули вроде `monty_api.py` и `currency_rate.py` выступают как сервисные интеграции. Это позволяет легко масштабировать бота и добавлять новых провайдеров.
